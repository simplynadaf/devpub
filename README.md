# devpub

> Write in your editor. Publish to Dev.to. Track what works.

```bash
pip install devpub
```

## Quick Start

```bash
# Initialize project
devpub init

# Pull your existing articles
devpub pull

# Create a new article
devpub new "My Article Title"

# Publish to Dev.to
devpub push -f articles/my-article.md

# Check analytics
devpub stats

# Discover trending topics
devpub trends
```

## Features

- 📝 **Write anywhere** — VS Code, Vim, any editor
- 🔄 **Git-backed** — version control, never lose a draft
- 🚀 **One-command publish** — `devpub push` and done
- 📊 **Terminal analytics** — views, referrers, heatmaps
- 🔥 **Trend discovery** — know what's hot before you write
- 🧠 **Semantic search** — find articles by meaning, not keywords
- ✅ **Validation** — catch issues before publishing
- 📅 **Scheduling** — write now, publish later
- 🌐 **Cross-platform** — Dev.to, Hashnode, Medium (coming soon)
